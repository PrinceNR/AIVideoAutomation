# Vocabulary Video AI

## Overview
An AI-powered application that generates English vocabulary lessons and converts them into educational videos.

## Features

- AI vocabulary generation
- Multi-language translations
- Example sentences
- Pronunciation
- Image generation
- Audio generation
- Video generation
- YouTube upload (planned)

## Tech Stack

- Python
- Gemini API
- ElevenLabs
- FFmpeg
- MoviePy
